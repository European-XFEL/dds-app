Technical Documentation

Documentation of the physics, algorithms, and implementation details behind the SimEx-Debye Scattering Simulator.

See the code repository at: https://git.xfel.eu/simulation/simex-debye/.

Physics Simplifications
  • Gas-phase / isolated-solute scattering (no cage or intermolecular interference)
  • Independent atoms (tabulated form factors)
  • No Debye-Waller factors or thermal motion
  • Tabulated solvent thermal response
  • No explicit solute-solvent structural correlation

Simulation Details

The Debye Scattering Equation

The simulator computes scattering intensity via the Debye scattering equation, which provides the orientational average for isotropic samples. We compute relative orientationally averaged molecular scattering (up to an overall scale factor); detector and beamline prefactors are handled separately or not modeled.

Difference Scattering Pipeline

For pump–probe time-resolved XSS experiments, the difference signal ΔI(Q)\Delta I(Q)ΔI(Q) combines solute structural change with solvent thermal response. Time dependence arises through the excitation fraction α(t)\alpha(t)α(t) and solvent heating parameters, not structural evolution.

Solute Difference

Load ground and excited state structures (XYZ), compute intensities:

ΔI(Q)=Iexcited(Q)−Iground(Q)\Delta I(Q) = I_{\text{excited}}(Q) - I_{\text{ground}}(Q)ΔI(Q)=Iexcited​(Q)−Iground​(Q)
Solvent Response

Load experimental (∂S/∂T)(\partial S/\partial T)(∂S/∂T) data and interpolate onto the Q grid.


This is multiplied by a scalar temperature rise (or fitted amplitude) to estimate the solvent contribution to the signal.

Combined Signal

The measured difference signal combines both contributions:

ΔI(Q,t)≈α(t)⋅ΔIsolute(Q)+β(t)⋅ΔIsolvent,unit(Q)\Delta I(Q,t) \approx \alpha(t) \cdot \Delta I_{\text{solute}}(Q) + \beta(t) \cdot \Delta I_{\text{solvent,unit}}(Q)ΔI(Q,t)≈α(t)⋅ΔIsolute​(Q)+β(t)⋅ΔIsolvent,unit​(Q) where α(t)\alpha(t)α(t) is the time-dependent excited state fraction, and β(t)\beta(t)β(t) is the solvent-heating amplitude (e.g., proportional to temperature jump).

Usage

1. Load Structures

Upload XYZ or PDB files for ground and excited states. Structures are parsed via SimEx-Lite SampleData to extract atomic numbers and positions.

2. Configure Solvent

Select a solvent with (∂S/∂T)(\partial S/\partial T)(∂S/∂T) differential data. Set concentration to scale the solute contribution relative to the solvent background.

3. Set Pump Parameters

Define photon energy (eV), excess energy deposited as heat per absorption, and excitation fraction (α(t)\alpha(t)α(t)). The heat deposition is used to estimate temperature jump and solvent response amplitude.

4. Detector Geometry

Configure sample-detector distance and beam center. Supports European XFEL detectors with module layouts.

5. Compute & Analyze

View ΔI(Q)\Delta I(Q)ΔI(Q) with separated contributions: total signal, scaled solute difference (α⋅ΔIsolute\alpha \cdot \Delta I_{\text{solute}}α⋅ΔIsolute​), and solvent thermal response. Identify optimal Q-ranges for your experiment.

6. Compare & Export

Compare multiple simulation configurations, save results for analysis, and use predictions to optimize beamtime parameters.
